## 🚀 Featured Projects

### 🧠 Adaptive RAG Mental Health Chatbot

A chatbot for mental health and CBT topics. It combines naive RAG and graph RAG so it can adapt how it retrieves information based on the question.

- 🔗 [Source code](https://github.com/dimitrichakma/mental-health-chatbot)
- 🌐 [Live demo](https://mental-health-chatbot.up.railway.app)
- 🧩 Concepts: Naive RAG, Graph RAG, adaptive retrieval
- ☁️ Deployed on Railway

### 📈 AI Habit Tracker

A full AI app that tracks habits and remembers the user over time. It was built in phases, from a simple agent to a production deployment.

- 🔗 [Source code](https://github.com/dimitrichakma/habit-tracker)
- 🤖 Agent built with FastAPI, LangGraph, and Claude
- 🧠 Long term memory using RAG with PostgreSQL and pgvector
- ✅ LLM as a Judge evaluation suite with DeepEval
- 🛡️ Safety guardrails and LangSmith tracing
- 🐳 Deployed with Docker, Railway, Streamlit Cloud, and Neon Postgres
